## Substituições e pool original

O pool original de 50 intenções foi tratado como candidato, não como obrigação.
As intenções sem correspondência inequívoca foram substituídas por movimentos
comuns acima, documentados pelo próprio `intentKey`; nenhuma substituição é feita
automaticamente em runtime. O manifesto não inclui itens rejeitados.

## Regeneração e verificações

- comando de coleta/revisão: `npm run curate:wger-starter-pack`;
- validação determinística: `npm run validate:wger-manifest`;
- a consulta usada para esta revisão foi o catálogo `exerciseinfo` do Wger;
- o dump bruto futuro fica somente em `artifacts/curation/`, ignorado pelo Git;
- o manifesto é carregado como objeto estruturado; não há contagem por regex.
